### 4. 机制解释

### 5. 分型鉴别与不确定性

当前倾向：type_2_vwd（moderate）。
VWF 多聚体分析和 VWF:CB/Ag 比值是区分 2A、2B 和 2M-A1 轴的关键检查；当前结果缺失，不能仅凭 AI 模型确定亚型。
建议优先补充：VWF_MULTIMER, VWF_CB, VWF_FVIIIB。
